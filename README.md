# Que-es-la-inyeccion-de-prompt-indirecta?

La inyeccion de prompt indirecta es cuando se oculta instrucciones maliciososas en lenguage natural (cualquier cosa que la IA interprete como una orden), para hacer que la IA de haga multiple cosas que tu no le pedistes que haga.

# Es-grave-este-problema? 
Si. La inyeccion de prompt indirecta puede tener graves consecuencias. Puede enviar informacion importante sin que te des cuenta. 

# Como-se-podria-parar? 
Una de las formas de las que se puede parar es entrenar bien la IA que se va a usar para ensenarle a evitar cier.

# Que-se-va-a-hacer?
Un bot de discord con una IA integrada y una demonstracion de como sucede, porque pasa, y como se ve con el problema resuelto.
